# Student Marks Analysis Using Python

## Purpose
This is a beginner-level data analysis project built to understand how Python can be used to organise, clean, and analyse student academic performance data. It supports my career goal of becoming a Data Analyst.

## Tools Used
* **Programming Language:** Python 3
* **Data Structures Used:** Lists and Dictionaries
* **Environment:** Visual Studio Code

## Implementation
1. Created a structured dataset of student names and their subject marks.
2. Wrote functions to calculate total marks, percentage, class average, highest score, and lowest score.
3. Assigned performance grades based on percentage criteria.
4. Generated a clean summary report in the console output.

## Outcome
This project helped me practise data handling, logical conditions, and summary statistics in Python before moving on to advanced libraries like Pandas and Matplotlib.
